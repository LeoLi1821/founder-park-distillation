# 三阶蒸馏 · 怎么做（系统建模）
> Founder Park 2026.1-7 知识体系 | 蒸馏日期：2026-07-28

## 一句话概述

Founder Park的知识体系建模为AI创业认知操作系统——属性是「怎么看AI创业」，方法是「怎么判断和执行」，路由是「不同场景用什么策略」。

## 类-属性-方法-路由模型

```
AI创业认知操作系统（Class: FounderParkCognitiveSystem）

属性（Attributes）—— 怎么看AI创业：
├── 技术认知：Harness > 模型 > Prompt
├── 竞争认知：模型公司做不了的才是方向
├── 组织认知：AI-Native > 用AI的传统组织
├── 全球化认知：出海是Day 1决策
└── 数据认知：真实工作流数据是核心资产

方法（Methods）—— 怎么判断和执行：
├── Agent产品开发：模型→Harness→上下文→Loop
├── 护城河判断：Benchmark可衡量→不做；工作流粘性→做
├── 出海架构：特拉华C-Corp + Vesting + QSBS
├── 组织改造：FDE + Agent开放 + 流程压缩
├── 增长方法：达人营销全漏斗 + ToC增长
└── 品味培养：dogfooding + 信号分辨

路由（Routes）—— 场景适配：
├── 做Agent产品 → Harness工程 + 能力公式
├── 做AI硬件 → 硬件是脚手架 + Agent是壁垒
├── 建AI组织 → FDE + YC改造 + 压缩成Agent
├── 出海创业 → C-Corp + 达人营销 + 收款
├── 选方向 → Benchmark避坑 + Mission驱动
└── 默认 → 尊重常识 + 快速验证
```

| 层面 | 设计内容 |
|------|---------|------|
